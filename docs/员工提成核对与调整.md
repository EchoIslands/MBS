# 员工提成核对与调整

更新：2026-11-16。业务依据：项目主人确认“服务实收金额 × 每位发型师比例”。本功能已完成本地开发和隔离验证，尚未部署生产056；不能据此认定线上已生效。

## 店长怎么用

入口：店铺端首页概览 → 员工提成与审核；负责人也可在财务报表进入。仅负责人、店长可查看和操作本店记录。

1. 点击员工的“设置比例”，填写百分比和至少4字原因。没有默认比例；允许明确配置0%。新比例只影响之后完成的结算，不改写历史记录。
2. 查看新结算流水。服务项目按明细归属员工计提，商品不参与；明细没有员工时尝试原预约员工，仍无法确定则显示“待指定员工”。次卡等零价服务不虚增提成。
3. 对“待配置比例”“实收待核对”点击“核对并计提”，根据原结算凭据填写该员工服务实收、归属员工、比例和原因。整单优惠导致明细金额与实收不一致时，系统不会猜测分摊方式。
4. 已计提记录需要修正时点“调整金额”，填写最终提成和原因。系统保存原始提成及调整差额，不删除原流水；可展开审计记录核对操作者和前后值。
5. 多人同时操作导致记录变化时，旧页面提交会拒绝覆盖，请刷新重新核对。网络超时后同一表单重试使用同一请求标识，避免重复记账。

人工核对的服务基数不得高于该条原始基数，同结算已批准基数合计不得超过原单实收；最终提成不得高于该员工服务基数。无归属明细合并为一条待核对记录；若需拆分给多位员工，当前入口不支持拆分，应先保留待核对，不将其随意归给某人。

## 退款、历史与统计边界

- 仅申请或批准退款不会冲正。原单全额退款已完成，并有退款金额、凭据、时间和经办人时，自动把关联提成标记为已冲正，另留负数冲正审计；重复完成不重复冲正。
- 没有原单关联、缺少凭据或非全额的历史退款不自动推算提成。需人工核对，不把“审批通过”当成钱已退回。
- 不追溯生成056安装前已完成的结算，不用今天的比例重算过去工资。
- 列表最多最近500条提成、100条审计，超过时提示截取；本页合计仅统计已计提/已调整且未冲正记录，不是全店累计工资。系统不执行工资发放，也不表示员工已经收到款项。
- 比例配置保存版本，新单保存当时比例和版本；服务明细、原结算、调整、退款审计可追溯。员工配置审计不包含密码等完整员工档案。
