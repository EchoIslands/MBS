## 第一章 快速上手

### 1.1 怎么登录店铺端

1. 打开店铺端网址（店铺管理后台）。
2. 输入你的**手机号**和**登录密码**。
3. 系统会根据你的**角色**（老板 / 店长 / 客服 / 发型师 / 收银员）自动显示相应的功能菜单。
4. 登录后进入「首页概览」，左上角显示你的姓名和角色。

> 提示：不同角色看到的菜单不一样。比如「财务报表」只有老板（CEO）能看到；发型师只能看到「发型师看板」里自己的业绩。

### 1.2 界面布局怎么看

- **顶部栏**：左边显示店铺名和当前页面名，右边是你的头像（点击可编辑个人资料）和「退出」按钮。
- **左侧（电脑）/ 底部（手机）**：导航菜单，点击切换功能页。
- **主内容区**：显示当前功能页的表格、卡片、按钮等。

### 1.3 编辑个人资料

1. 点击右上角你的**头像**。
2. 弹出「个人资料」窗口，可修改：头像（点圆形头像**拍照 / 从相册选**，或粘贴图片网址）、姓名、手机号、职位、专长、新密码。
3. 点「保存」。密码留空表示不修改。

## 第二章 日常经营核心流程

这一章是每天都会用到的功能，建议重点熟悉。

### 2.1 首页概览（今日工作台）

- **在哪里**：登录后默认进入；导航菜单「首页概览」。
- **能看到什么**：
  - 4 张数据卡：今日预约数、待处理、已完成、今日营收。
  - 今日预约列表（前 5 条，含排队号、客户、服务、发型师、价格、状态）。
  - 最近客户列表。
- **能做什么**：点卡片上的快捷入口，直接跳到客户、评价、看板、会员、财务等页面。点「编辑我的资料」修改个人资料。

### 2.2 预约管理 ★（每天最常用）

- **在哪里**：导航菜单「预约管理」。
- **看到什么**：
  - 顶部 4 张统计卡：待确认 / 今日 / 本周 / 本月完成数。
  - 筛选栏：关键字搜索、状态下拉、发型师下拉、日期选择，以及「列表视图 / 看板视图」切换。
  - 看板视图：按「待确认 / 已确认 / 已完成 / 已取消」分 4 列展示预约卡片（卡片含排队号、客户、服务、时间、发型师、价格）。
- **预约详情能做什么**（点任意预约卡片打开弹窗）：

| 操作 | 什么时候用 | 谁可以做 |
|------|-----------|---------|
| 确认预约 | 顾客的待确认预约要转成已确认 | 店长 / CEO / 客服 |
| 开始服务 | 顾客到店，开始服务（自动记录开始时间） | 店长 / CEO / 客服 / 该发型师 |
| 完成服务 | 服务结束 → 自动跳到「开单结算」页收款 | 同上 |
| 客户未到 | 预约了但没来 | CEO / 客服 |
| 取消预约 | 顾客或店铺要取消 | CEO / 客服 |
| 调配发型师 | 换一个发型师服务该顾客 | 仅 CEO / 店长 |
| 改预约时间 / 服务时间 | 调整预约或实际服务时间 | 店长 / CEO / 客服 / 该发型师 |
| 延时通知 | 服务临时增项延长，需通知后续受影响顾客（见 2.3） | 店长 / CEO / 客服 / 该发型师 |

### 2.3 延时通知（服务超时，避免后续顾客干等）

**场景**：顾客按约到店，服务过程中临时加项目（要延时），会顶到发型师后面的顾客。

1. 打开该顾客的**预约详情**（状态为「已确认」且你有权限时）。
2. 找到「**延时通知**」区块，点「延时」。
3. 输入**预计延时时长（分钟）**，可选填原因（如「临时加烫染」）。
4. 点「**确认延时并通知**」。
5. 系统会自动找出同一发型师、时间上会撞上的**后续预约**，把这几位顾客标记为「待顾客处理」，并提示「已通知 N 位受影响顾客」。
6. 这些顾客会在自己的「我的预约」里看到提醒，可选择**改时间**或**联系门店**。
7. 若顾客 **4 小时内没处理**，状态会自动变成「超时未响应」，需要你电话跟进。

### 2.4 开单结算 ★（收银核心）

- **在哪里**：导航菜单「开单结算」。
- **能做什么**（一个完整的收银流程）：

| 步骤 | 操作 |
|------|------|
| 1. 选客户 | 搜索姓名 / 手机 / 会员号，选客户；也可以现场「新建客户」 |
| 2. 带预约 | 从预约页跳进来时，会自动把该预约的服务加进购物车 |
| 3. 加项目 | 加服务（可指定发型师等级，金牌 +20 元、总监 +40 元）、加商品 |
| 4. 次卡抵扣 | 客户有次卡时，下拉「次卡抵扣」选对应次卡，对应服务记 ¥0，提交后自动扣减剩余次数 |
| 5. 团购券核销 | 扫码或手动输券码，验证后抵扣对应项目 |
| 6. 会员折扣 | 系统自动算「购买型 VIP 折扣 × 储值折扣」的折上折，并累计积分 |
| 7. 手动改价 | 仅**收银员 / CEO** 可见；只能**降价**，最低不超过「钻石 5.8 折 × 随心卡 7 折 ≈ 4.06 折」，低于会被拦截 |
| 8. 选支付方式 | 现金 / 微信 / 支付宝 / 银行卡 / 储值余额（优先扣储值，不足再补） |
| 9. 微信支付 | 生成二维码，顾客扫码，确认到账后完成 |
| 10. 确认结算 | 提交，成功后打印小票 / 跳结算详情 |

- **未完成结算找回**：如果从预约跳进来、中途退出了，下次进入结算页顶部会显示「继续上次未完成结算」，点它就能找回草稿继续收款。

### 2.5 结算管理（结算记录查询 / 补录）

- **在哪里**：导航菜单「结算管理」。
- **能做什么**：
  - 搜索客户、按支付方式 / 状态筛选结算记录。
  - 查看结算详情（项目清单、折扣明细、次卡 / 团购券抵扣明细）。
  - **新建结算**（补录）、**确认收款**、**删除**、**重新生成微信支付二维码**。

## 第三章 客户运营

### 3.1 客户管理（客户列表 + 详情）

- **在哪里**：导航菜单「客户管理」。
- **看到什么**：统计卡（总客户 / 会员数 / VIP 数 / 储值数）、搜索栏、标签筛选（剪发 / 烫发 / VIP / 股东等）、客户卡片列表。
- **能做什么**：
  - **添加客户**（CEO / 店长 / 客服 / 收银）：姓名、手机、性别、年龄、生日、购买型 VIP 等级、储值等级、储值余额、来源、是否股东。
  - **编辑客户**（CEO / 店长 / 客服）。
  - **导出 CSV**（仅 CEO，含 15 个字段）。
  - 点客户卡片看**详情弹窗**：累计消费、储值余额、积分、推荐提成、会员折扣、客户画像、到店记录等。
- **数据范围**：发型师只能看到自己服务的客户；其他角色按权限看全部或部分。

### 3.2 客户表格管理（表格化视图 + 完整导出）

- **在哪里**：导航菜单「客户表格管理」。
- **能做什么**：
  - 用 8 张统计卡总览：总客户、会员数、股东数、总营收、总储值余额、共享基金、可消费余额、有预约数。
  - 24 列完整表格视图（含联系方式、微信、身份证、消费项目、余额、积分、转介绍等）。
  - 关键字 / 会员等级 / 是否会员 / 预约 / 推荐筛选。
  - **导出 CSV（24 字段完整导出）**、查看详情、编辑、新增、删除。

### 3.3 客户画像（记录顾客偏好）

- **在哪里**：导航菜单「客户画像」。
- **能做什么**：为每位顾客结构化记录偏好，方便下次服务：
  - 发型偏好、发色偏好、烫染偏好、护理偏好、发质类型、头发长度、到店频率、消费预算、沟通风格、附加服务（头部按摩 / 修胡须等）、到店时间偏好、备注、过敏信息、推荐产品。
- **怎么用**：在「客户管理」里选某客户 → 底部「编辑画像」，或直接进「客户画像」页保存。

### 3.4 客户智能召回（唤醒沉睡客户）

- **在哪里**：导航菜单「客户智能召回」。
- **能做什么**：系统按「流失风险（高 / 中 / 低）+ 上次到店天数」排序客户，为每人**生成推荐召回话术**，并提供「发微信 / 发短信 / 电话回访」按钮。
- 注意：当前「发微信 / 发短信」为**前端模拟**（点完按钮变「已发微信」），实际触达需通过微信渠道（详见《微信渠道接入规划与指南》）。

### 3.5 客户洞察（经营分析 + 一键召回券）

- **在哪里**：导航菜单「客户洞察」（仅 CEO / 老板 / 客服可进）。
- **能做什么**：
  - 看 RFM 客户分层饼图、近 30 天营收趋势、热门服务排行。
  - 识别「高价值活跃 / 活跃维护 / 沉睡预警 / 流失客户」，对沉睡 / 流失客户一键「发送召回券」（自动生成 ¥50 券发到该客户）。
  - 查看运营建议。

### 3.6 满意度回访

- **在哪里**：导航菜单「满意度回访」（仅 CEO / 客服）。
- **能做什么**：手动发起回访——选客户 → 选历史预约 → 填评分（1~5 星）、是否推荐、评语 → 提交。列表可查看历史回访记录、按评分筛选。

### 3.7 评价管理

- **在哪里**：导航菜单「评价管理」。
- **能做什么**：
  - 看店铺评价（服务态度 / 技术水平 / 环境 / 性价比 4 维度）和技师评价（技术 / 态度 / 沟通）。
  - 看星级分布、按星级筛选。
  - **回复评价**（所有角色）、**隐藏 / 显示评价**（仅 CEO / 老板 / 店长）。

## 第四章 会员与营销

### 4.1 会员管理（开卡 / 撤销 / 权益）

- **在哪里**：导航菜单「会员管理」（CEO / 店长 / 客服）。
- **能做什么**：
  - 看客户会员 / 储值 / 股东标签、双轨会员等级筛选。
  - 点客户卡片看**详情**：已开通会员等级与折扣、权益使用记录、推荐记录、**次卡列表**。
  - **开通购买型 VIP**、**开通储值会员**（弹窗选等级）。
  - **撤销会员**（仅 CEO / 客服）：撤销后降为普通用户，储值余额、股东身份、次卡剩余次数不受影响。

### 4.2 会员权益配置（折扣规则）

- **在哪里**：导航菜单「会员权益配置」。
- **能做什么**：配置双轨会员体系的折扣与权益：
  - 购买型 VIP：普卡 / 银卡 / 金卡 / 钻石。
  - 储值会员：储值卡 / 安心卡 / 顺心卡 / 随心卡。
  - 特殊 VIP：可自定义新增 / 编辑 / 删除（名称、折扣、积分倍率、权益、颜色）。
- **谁可以改**：仅 **CEO** 可点「保存配置」；其他角色可浏览。

### 4.3 次卡管理（发行 / 核销记录）

- **在哪里**：导航菜单「次卡管理」（CEO / 店长）。
- **能做什么**：
  - **新增次卡**：选客户、选服务、次卡名称、总次数、价格、有效期、是否节假日可用、活动类型（如「99 元 3 次（自动入会钻石会员）」）。
  - 查看每张次卡的**剩余次数 / 有效期 / 状态（有效 / 已用完 / 已过期）**、使用记录（核销时间 / 核销人）。
  - 编辑 / 删除（仅 CEO / 店长）。

### 4.4 优惠券管理

- **在哪里**：导航菜单「优惠券管理」（CEO / 店长）。
- **能做什么**：创建 / 编辑 / 停用店铺自营优惠券：
  - 类型：固定金额 / 百分比 / 买赠。
  - 适用范围：全场 / 指定商品 / 指定服务。
  - 数量（-1 表示无限）、每人限领、有效期、上下架。

### 4.5 外部团购券（美团 / 抖音核销）

- **在哪里**：导航菜单「外部团购券」（CEO / 店长）。
- **能做什么**：
  - 建立**批次**：平台（美团 / 抖音 / 大众点评 / 其他）、价格类型（固定 / 按服务自定义 / 按会员等级折扣）、服务项目、有效期、总数量。
  - **核销团购券**：输券码 → 验证显示券信息 → 绑定客户 → 核销。
  - 查看批次详情和券码列表（全部 / 已用 / 未用）。

### 4.6 退款管理

- **在哪里**：导航菜单「退款管理」（CEO / 店长）。
- **能做什么**：处理退款申请（按 48h / 24h 超时用红 / 橙 / 黄边框提示优先级）：
  - **批准**：选退款方式（原路退回 / 储值余额 / 银行卡）。
  - **拒绝**：填拒绝原因。

## 第五章 商品经营

### 5.1 商品管理（商品 + 库存 + 图片）

  - 备货 / 完成备货、**自提核销**（输自提码）、**发货**（选快递公司 + 填单号）、取消、查看详情、退款申请。

## 第六章 店铺设置

### 6.1 店铺设置（基本资料 + 服务 + 员工）★

- **在哪里**：导航菜单「店铺设置」（CEO / 店长）。

#### （1）店铺基本信息

- 修改店铺名称、描述、电话、地址，点保存。

#### （2）营业时间

- 周一至周日，每天可开 / 关「是否营业」，设置开门、关门时间，点保存。

#### （3）预约确认模式

- 选择「自动确认」或「手动确认」。手动模式需要店员在「预约管理」里逐条确认。

#### （4）股东权益配置

- 配置股东权益：开关、服务折扣率（默认 0.8）、商品折扣率（默认 0.85）、奖励金率（默认 0.05）、每月免费服务数（默认 1）、优先预约开关、生日福利文本。
- 注意：股东权益所得**只能用于店内消费，不可提现**。

#### （5）服务管理 ★（很重要）

- **新增服务**：名称、价格、时长（分钟）、**「金牌专属服务」开关**、**「店长专属服务」开关**。
- **服务列表**：每行显示名称 / 价格 / 时长 / 金牌 / 店长标签，可编辑、删除。
- **金牌专属服务**：只有「金牌发型师」能接；顾客选这项时，普通发型师会被置灰并提示「该服务需金牌发型师」。
- **店长专属服务**：只有「店长」能接；顾客选这项时，其他发型师会被置灰并提示「该服务需店长」。

#### （6）员工管理 ★（很重要）

- **新增员工**：姓名、手机、专长、头像、**岗位**（一个下拉，分两栏：**可上钟预约** = 发型师 / 金牌发型师 / 店长；**后台员工** = CEO/老板 / 客服 / 收银）、密码。
- **员工列表卡片**：头像、姓名、岗位、专长、手机、岗位徽标、编辑、删除。
- **岗位徽标规则**：
  - 选「发型师」→ 显示「发型师」徽标；
  - 选「金牌发型师」→ 显示「金牌发型师」徽标；
  - 选「店长」→ 自动显示「金牌 + 店长」双徽标（店长天然具备金牌资格，可接金牌专属服务）。
- **权限**：
  - CEO 可新增所有岗位；店长只能新增「发型师」类岗位。
  - CEO 可编辑 / 删除所有人；店长只能编辑 / 删除发型师类员工。
  - 编辑时不能对自己的岗位降权（防止老板 / 店长误把自己降成普通发型师）。

## 附录 C：常见问题

**Q1：为什么我的菜单比店长少？**
A：菜单是根据你的角色自动显示的。比如发型师看不到财务报表和会员管理。

**Q2：顾客预约时显示「该服务需金牌发型师」，但明明有空发型师？**
A：说明这项服务在「店铺设置 → 服务管理」里勾选了「金牌专属服务」，只有金牌发型师能接。普通发型师会被置灰并提示那句话。

**Q3：结算时想给顾客便宜点，怎么改价？**
A：仅收银员和 CEO 能改价，且只能降价，最低到「钻石 5.8 折 × 随心卡 7 折」左右。低于这个数系统会拦截。

**Q4：开单交到一半不小心退出了怎么办？**
A：再次进入「开单结算」页，顶部会提示「继续上次未完成结算」，点它找回草稿继续。

**Q5：顾客到了没做项目怎么处理？**
A：在预约详情里点「客户未到」（仅 CEO / 客服）。

**Q6：服务中途临时加项目，怕耽误后面顾客，怎么办？**
A：在预约详情里点「延时 → 输入延长分钟数 → 确认延时并通知」，系统会自动通知可能受影响的后续顾客。

**Q7：怎么给顾客发次卡？**
A：「次卡管理 → 新增次卡」。选顾客、选服务、填总次数和价格即可。

**Q8：股东的钱能提现吗？**
A：不能。股东推荐收益所得只能用于店内消费，系统不提供任何提现入口。
## 2026-10-21 待发布操作补充：顾客本人登录

以下为本地整改后的待发布流程，不代表线上已有此功能；请等项目主人确认发布与培训后使用。

1. 顾客首次输入手机号后设置六位数字密码，之后使用手机号和密码登录；小程序会缓存会话，后续打开时自动恢复。
2. 忘记密码时，顾客联系门店。CEO/客服在客户详情执行“重置顾客密码”，新密码为手机号后六位，并通过可靠方式告知顾客本人。
3. 顾客可在个人中心查看本人余额、资料、次卡和订单。客户档案手机号需由门店维护准确；手机号本身不等同于已验证的本人身份。
4. 员工原密码不变；更新后原会话可能要求重新登录，用原密码即可。首次登录自动转换哈希存储，不需要管理员批量重置密码。
5. 旧客户端不能仅凭手机号登录；发布时须配套更新小程序和门店说明。该临时方案尚未实现短信或微信自动身份验证，运营负担及后续方案待审核。
