# 小程序分享修复计划

## 原因与范围

- 主人截图显示个人中心右上角菜单“当前页面未设置分享”。代码仅首页、商城、商品详情及邀请页有分享回调，其他 Page 未注册；本次先修复已证实的技术缺漏，不据开发工具断言账号政策或正式版分享验收通过。
- 在现有全局 Page 注册入口统一补齐好友分享，保留密码守卫、原生命周期与返回值。所有无专用分享的页面只分享店铺首页，不复制当前页面参数、顾客编号、凭证、手机号、订单号或财务信息。
- 所有缺省分享封面使用随代码打包的固定图片，避免默认页面截图泄露个人中心会员/余额信息。已有商品与邀请分享保持原用途；未明确提供朋友圈分享的私密页面不开放朋友圈，因为其路径不能替换为首页。
- 仅改小程序代码与分享资源，不改登录权限、数据库、价格、优惠和推荐奖励规则。保留主人私有编译配置，与退款返回导航同批验收。

## 验收

1. 使用实际全局 Page 包装器验证好友分享菜单、生命周期返回、强制改密守卫以及没有 onShow 的页面；分享异常不阻断页面显示。
2. 合成个人中心/支付/退款/登录上下文不出现在卡片标题、路径或封面中；既有商品与邀请分享仍有效；固定封面存在且打包引用可达。
3. 本地生产构建、合成配置后端启动及健康请求检查；原生编译和菜单可用单独记录。
4. 主人重新编译后查看个人中心菜单，真机预览“发送给朋友”，接收方打开后只能访问自己的账号。发布须重新上传小程序；不代实际发送、推送、上传或审批。
