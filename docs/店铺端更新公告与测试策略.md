# 店铺端「版本更新公告 + 重点测试」策略与指引

> 目的：让店铺方（老板 / 店长 / 店员）在每次功能更新后，能快速知道自己能用什么新功能，并按清单做针对性的验收测试，而不是「系统变了却不知道」。
> 版本：v1.0 ｜ 更新日期：2026-10-16

---

## 一、策略总览（一图看懂）

```
每次功能上线
    │
    ├─ ① 产出一份《版本更新公告》（白话，讲「新增了什么、在哪点、怎么用」）
    │
    ├─ ② 配套一份《重点测试清单》（分角色、带预期结果，照着点一遍）
    │
    ├─ ③ 推送给店铺方（微信群 / 店铺端登录弹窗）
    │
    └─ ④ 收集反馈 → 形成「已测通过 / 有问题」结论 → 修复后关闭
```

**核心原则**：对外只讲「能用什么、怎么用」，不讲「后端改了路由 / 字段」这类技术黑话。测试清单必须「可照着点、有明确预期结果」。

## 二、四条落地机制

### 机制 1：版本更新公告（让店主「知道」）

- **定位**：一份白话版「本次更新了什么」。
- **内容结构**（每条更新固定四要素）：
  1. **新增了什么**（一句话）
  2. **在哪里点**（菜单路径）
  3. **怎么操作**（大白话步骤）
  4. **什么场景用**（举个店里的例子）
- **复核红线**：通读一遍，如果一句话里出现「数据库 / 接口 / SQL / 序列化」等词，就删掉换成白话。

### 机制 2：重点测试清单（让店主「能验证」）

- **定位**：配套公告，按**角色**分组，每条指令都带「**预期看到什么**」。
- **核心要求**：每条测试项必须能回答「点完这一步，看到什么才算对」。
- **优先级标注**：`P0 必测` / `P1 建议测`，让店员优先测高频、易错的功能。

### 机制 3：推送渠道（让公告「被看见」）

| 渠道 | 成本 | 建议 |
|------|------|------|
| 微信小店群发文档 / 图文 | 低 | **v1 首选**，直接把公告 + 测试清单发到店长群 |
| 店铺端登录后弹「更新公告」弹窗（一次性） | 中 | **v2 建议做**，登录即见，最不容易漏 |
| 店铺端首页「更新公告」横幅 / 入口 | 中 | 与弹窗二选一或合并 |
| 打印张贴在收银台 | 低 | 辅助，适合大版本 |

> **v1 最小落地**：先做「文档 + 微信群里发」。店铺端登录弹窗作为后续改进项（需要前端新增一小段代码）。纯依赖店员「自己去看文档」不可靠，必须主动推送。

### 机制 4：反馈闭环（让问题「能回来」）

统一反馈模板，让店员发现异常时能用一句话描述清楚：

```
【问题反馈】
- 哪个页面 / 菜单：
- 点了什么按钮：
- 预期结果（参照测试清单）：
- 实际看到什么：
- 截图：
```

收到反馈后由开发标记为「已测通过 / 待修复」，修复后再让店铺复测确认。

## 三、本次更新公告（可直接发给店长）

> 面向店铺方，白话版。以下为 2026-10 最新一批功能。

### 1. 预约延时通知（新）
- **新增了什么**：服务进行中临时加项目要超时，可以一键通知后面被影响的顾客。
- **在哪里点**：预约管理 → 点开该顾客的预约详情 → 「延时通知」→ 点「延时」。
- **怎么操作**：输入延时的分钟数（可填原因）→ 点「确认延时并通知」。
- **什么场景**：顾客临时加烫染、要延长 40 分钟，会顶到发型师下一单；点一下，后面撞时间的顾客就会在「我的预约」收到提醒，可自己改时间或打电话给门店。

### 2. 金牌发型师 & 店长专属服务（新）
- **新增了什么**：可以给「服务」打两个标记——「金牌专属」「店长专属」，只有对应的人能接。
- **在哪里点**：店铺设置 → 服务管理（服务编辑里有两个开关）；员工管理里给发型师开「金牌发型师」。
- **怎么操作**：先把技术好的发型师标记为「金牌」，再把高端服务勾上「金牌专属」。
- **什么场景**：高价位精剪只让金牌老师做；顾客预约时，其他发型师会变灰并提示「该服务需金牌发型师」，避免顾客误选。

### 3. 次卡系统升级（新）
- **新增了什么**：
  - 钻石会员**自动赠送 3 次「设计师洗剪吹」**次卡。
  - 会员详情里能看到次卡（办了哪张、剩几次、有效期）。
  - 次卡编辑可改服务项目 / 次数 / 价格。
  - 结算页可用**次卡抵扣**，提交后自动核销。
  - 开单交到一半退出，可**找回未完成结算**继续。
- **在哪里点**：次卡管理、会员管理、开单结算。
- **什么场景**：顾客拿次卡来剪发，结算里选「次卡抵扣」，这项就记 0 元并扣一次次数。

### 4. 结算「手动调价」（新，仅收银员 / 老板）
- **新增了什么**：结算时可以给顾客**降价**（不能加价），但有最低限价。
- **在哪里点**：开单结算 → 对应项目旁「改价」。
- **什么场景**：老顾客给个优惠，在允许范围内调低价格。

### 5. 商品多图展示（新）
- **新增了什么**：商品可传**最多 6 张图**，第一张是主图，顾客端可点缩略图切换看细节。
- **在哪里点**：商品管理 → 编辑商品 → 图片区批量上传。
- **什么场景**：假发 / 造型产品录多角度图，顾客看得更清楚。

### 6. 股东权益调整（重要）
- **新增了什么**：股东推荐收益**只能店内消费，不能提现**，会员信息里显示「可消费余额」，全店（含小程序）不再有「提现」入口或字样。
- **注意**：如遇顾客询问「能不能提现」，统一口径为「可在店内消费」。

### 7. 其他体验优化
- 店长现在会出现在可预约的发型师名单里。
- 员工头像支持拍照 / 本地上传。

## 四、本次重点测试清单（照此验收）

> 标记：`P0` 必测（核心、易错），`P1` 建议测。测试后逐项填「通过 / 不通过」。

### A. 店长 / 老板（管理员）测试

| 编号 | 优先级 | 操作步骤 | 预期看到什么 |
|------|:---:|------|------|
| A1 | P0 | 店铺设置 → 服务管理 → 新增服务「总监剪发」，勾「金牌专属」 | 服务列表里该服务带「金牌」标签 |
| A2 | P0 | 店铺设置 → 员工管理 → 编辑某发型师，打开「金牌发型师」并保存 | 该员工卡片出现「金牌发型师」标签 |
| A3 | P0 | 顾客端选「总监剪发」预约 | 只有金牌发型师可选，普通发型师置灰，提示「该服务需金牌发型师」 |
| A4 | P1 | 店铺设置 → 服务管理 → 新增服务「店长精剪」，勾「店长专属」，顾客端预约 | 只有店长可选，其他人置灰，提示「该服务需店长」 |
| A5 | P0 | 次卡管理 → 给某钻石会员看，确认有无自动赠送 3 次「设计师洗剪吹」 | 该会员详情里出现「设计师洗剪吹 ×3 次」次卡 |
| A6 | P0 | 预约管理 → 打开一条「已确认」预约 → 延时 → 输入 30 分钟 → 确认 | 提示「已通知 N 位受影响顾客」，后续撞时间的预约状态变「待顾客处理」 |
| A7 | P0 | 结算改价：开单结算 → 选项目 → 改价，输入一个低于「4 折」的价格 | 系统拦截，提示不能低于最低限价 |

### B. 收银员测试

| 编号 | 优先级 | 操作步骤 | 预期看到什么 |
|------|:---:|------|------|
| B1 | P0 | 开单结算 → 选顾客（有次卡的）→ 加对应服务 → 下拉「次卡抵扣」选该次卡 | 对应服务金额变 ¥0，提交后次卡剩余次数减 1 |
| B2 | P0 | 开单结算 → 从预约跳入并加项后退出页面 → 再进入结算页 | 顶部提示「继续上次未完成结算」，可找回草稿 |
| B3 | P1 | 开单结算 → 选项目 → 确认「改价」按钮可见（收银员 / 老板可见） | 改价按钮显示；普通店员看不到 |

### C. 发型师测试

| 编号 | 优先级 | 操作步骤 | 预期看到什么 |
|------|:---:|------|------|
| C1 | P0 | 预约管理 → （自己为发型师时）看发型师下拉 | 下拉隐藏，只显示「分配给我的预约」 |
| C2 | P1 | 发型师看板 | 只看到本人业绩与今日预约，看不到别人 |

### D. 顾客端（配合测试）

| 编号 | 优先级 | 操作步骤 | 预期看到什么 |
|------|:---:|------|------|
| D1 | P0 | 顾客「我的预约」里，被标记延时的预约 | 出现警示「发型师临时延时，请选择处理方式」，可「改时间」或「联系门店」 |
| D2 | P0 | 点「联系门店」 | 显示门店电话（小程序里直接拨号） |
| D3 | P0 | 商品详情页 | 主图 + 缩略图，点缩略图可切换大图，显示「1/6」计数 |
| D4 | P1 | 顾客端 / 小程序检查是否还有「提现」字样或入口 | 无任何「提现」入口，会员信息仅显示「可消费余额」 |

## 五、执行与维护约定

1. **每次功能上线**，同步产出「更新公告 + 测试清单」，发送到店长群。
2. **测试清单**由店铺方按角色分工执行，逐项勾选「通过 / 不通过」。
3. **异常反馈**按「问题反馈模板」（见机制 4）回流，开发修复后让店铺复测。
4. 本策略文档与《店铺端软件使用说明书》同放 `docs/` 目录，作为店铺培训与验收的固定材料。
