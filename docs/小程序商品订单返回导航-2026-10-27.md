# 小程序商品订单返回导航

日期：2026-10-27

## 范围与方案

个人中心进入“我的商品订单”后没有可见返回入口。页面使用 custom 导航，依赖自定义头部及未正常显示的箭头图标。改为微信原生白色导航栏，标题统一为“我的商品订单”，删除重复自定义头部，避免筛选栏占用微信胶囊区域。

有上一页时使用微信原生返回；直接打开而无上一页时显示“返回个人中心”入口，重新进入个人中心。自定义回退函数同时兜底 navigateBack 失败，不改订单查询、支付、退款、价格及数据。

## 验收

- 从个人中心进入后，顶部标题和返回箭头可见，返回原页面。
- 无页面栈时仍有明确返回个人中心入口；订单筛选与列表保留。
- 检查配置/处理函数、构建、本地 API 健康及实际微信开发者工具页面；区分代码验证和真机验证，不代提交/推送/上传，不写生产业务数据。

## 结果

- 原生导航配置、正常返回、navigateBack 失败兜底、无上一页返回个人中心的实际 Page 处理函数检查通过；本地生产构建通过，合成配置 API 健康 200，diff 检查通过。
- 微信工具进入个人中心后，继续进入订单的界面检查被主人按 Esc 终止，未确认最终订单页返回箭头及点按效果；不宣称真机验收通过。测试服务已在后续回合关闭。
- 主人随后按计划上传 1.1.0 并回传“代码上传成功”截图。截图不显示上传版本号，也不证明提交审核、审核通过或正式发布；体验版真机返回验收待补。
