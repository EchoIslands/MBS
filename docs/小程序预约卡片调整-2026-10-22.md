# 小程序个人中心预约卡片

需求：我的预约列表去掉店名，显示预约设计师姓名。当前和历史共用卡片，统一替换标题为“设计师：姓名”，无姓名显示“设计师：待安排”。沿用已有 barberName 数据映射及省略样式，不新增请求、不读取员工资料、不修改预约数据。验收：两类列表不显示店名，服务、状态、时间、价格及点击行为保留；设计师字段缺失有明确占位。仅修改小程序显示，不扩大到 H5。

本地修改完成，JS 语法、git diff --check 与 npm run build 通过（既有包体警告）；未做微信工具编译或真机验证。用户在微信开发者工具点击“编译”，进入个人中心→我的预约，分别切换当前/历史，预期每张卡片首行为“设计师：姓名”或“设计师：待安排”。预约详情弹窗的店铺信息保留。本轮不涉及后端或数据库。
