# 小程序顾客短信验证码登录

跨项目立项、审批倒排及验收节点的通用检查表见 [外部平台审批前置检查](external-approval-preflight.md)。本文件记录 MBS 的具体配置与当前状态。

已实现密码登录与验证码登录切换。短信支持新客注册和老客登录：合法手机号均可请求发送；校验成功后，新客自动创建基础档案，老客复用唯一档案。重复手机号档案拒绝自动选择或合并。不修改客户密码或身份核实状态。发送冷却 60 秒，验证码 5 分钟有效且只能使用一次；同手机号每天最多 5 次、同网络每天最多 20 次，连续输错 5 次后验证码失效，密码登录原有安全限流仍生效。临时弱密码账户必须先按原流程改密。

启用步骤：
1. 在阿里云短信服务开通国内短信，申请并获批与门店一致的短信签名，以及验证码模板；模板变量填写 `${code}`，支持六位数字。现有模板未写有效期；5 分钟有效由后端数据库校验。
2. 在 Vercel 项目的 **Environment Variables** 配置 `SMS_ACCESS_KEY_ID`、`SMS_ACCESS_KEY_SECRET`、`SMS_SIGN_NAME`、`SMS_TEMPLATE_CODE`。使用最小权限的短信服务凭据；不要把密钥放进 GitHub 或小程序。
3. 先在数据库执行 `migrations/045_customer_sms_login.sql`（可通过项目的 `scripts/setup-db.ts` 安装器），确认 RPC 建立。之后部署后端，再用微信开发者工具上传含登录页面改动的小程序版本。
4. 用已建档、非临时弱密码的真实手机号测试：验证码发送、错误码、过期、重发、首次登录和再次登录；检查短信账单。短信签名/模板和凭据未配置前，页面仍可使用密码登录，短信发送会明确提示未开通。

注意：短信发送会产生阿里云计费。模板已审核通过，但签名运营商报备仍待实际发送验证；生产凭据与新部署尚未核对，不能宣称线上短信登录可用。数据库安装与部署由项目负责人按既有上线流程执行。

## 2026-11-12 顾客会话有效期调整（本地待部署）

正常顾客密码/短信登录凭证及H5 Cookie统一由2小时改为登录起30天；小程序复用同一后端凭证。不是每次访问续期。强制改密受限凭证仍为2小时，员工7天不变；密码版本变更仍使旧凭证失效。H5恢复仅明确401清理会话，网络异常、503或无效响应保留缓存身份供重试，缓存不替代服务端授权；旧账号迟到响应不覆盖新账号。

无需SQL或新环境变量；后端与H5部署后生效，既有2小时凭证不会自动延长，需重新登录一次获得30天凭证。显式退出、清缓存、密码变更或JWT密钥更换仍可能提前结束会话。验证见 tests/customer-session-lifetime.test.ts 及既有安全/小程序会话回归。
