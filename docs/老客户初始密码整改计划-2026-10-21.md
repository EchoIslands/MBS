# 老客户初始密码整改计划

范围：仅对执行初始化时 password_hash 为空的顾客设置 bcrypt(123456)，逐条随机盐；已有密码不覆盖。初始化设 is_weak_password=true，清除身份核实状态。结构迁移和数据初始化分开，均不得自动执行。

工作量：中等规模，后端/SQL、原生小程序、H5 同步、回归与文档四部分；人工排期约 2–3 人日，不含微信真机、Supabase 隔离项目与生产发布验收。

验收：重复执行初始化不再次修改数据；已有哈希不变；初始密码登录只取得改密受限会话；恢复、深链、返回均进入改密页面；业务 API 从数据库检查标记；正确旧密码+不同的六位新密码才能解除限制；改密不写身份核实字段；旧 token 失效；未核实仍不能线上支付。全程仅本地，保留既有改动。
