# 实时预约排队：操作、规则与验收

状态更新：2026-11-12。项目主人反馈生产数据库 048 已执行成功，046、047 此前也已确认；未由维护者独立只读核验。配套代码推送、后端/H5 部署、小程序上传及现场验收仍待确认。

## 三端直接操作

| 使用者 | 入口 | 直接可用的操作 |
| --- | --- | --- |
| 顾客（小程序与 H5） | 个人中心 → 对应预约卡片的“查看排队 / 暂离 / 返回” | 暂离10/20分钟、报告已返回、确认看到叫号、请前台协助、直接致电门店 |
| 前台/客服、店长、CEO | 预约管理 → 实时排队工作台 | 确认到店、暂离、确认本人返回、准备返回提醒、正式叫号、过号、开始/结束计时、更新剩余时间、电话联系与沟通记录 |
| 发型师 | 发型师看板 → 实时排队工作台 | 仅本人预约：准备提醒、叫号、开始/结束计时、剩余10/20/30分钟、联系记录；暂停接客20分钟/恢复 |

前台可按发型师筛选、搜索姓名/电话，或一键只看待处理。待处理突出顾客报返回、求助、未确认叫号及等待超过45分钟；店长可查历史及更正时间。常规动作直接触达；优先安排/调序需要填写原因以留痕。

## 实时性与联系闭环

- 页面可见时约每5秒读取服务器；操作完成、回到前台和网络恢复时立即刷新。显示最后一次成功同步时间。
- 超过20秒未成功同步，或读取失败，页面明确标为过期并暂停业务操作；不离线补写、不把网络错误当成成功。电话入口仍可用。
- 小程序前台新叫号/准备提醒振动，H5 可手动开启页面提醒音。前台可开提示音，并看到未确认叫号与求助。
- 顾客点“我已看到”才记录收到确认；确认看到不代表已在服务位。前台应对未确认叫号直接致电，并登记“已联系/已沟通”。该记录是员工操作记录，不是运营商送达回执或通话接通证明。
- **锁屏、关闭页面、微信后台时，不保证页面轮询、振动或提示音送达。当前没有接入排队短信或微信订阅消息。已有登录验证码模板不能用于叫号。正式推广远程离店等待前，应配置并联调专用通知渠道；现阶段必须保留人工电话兜底，不能宣传离店后必然自动通知。**
- 5秒是轮询频率，网络耗时/故障会增加实际延迟，不是端到端送达承诺。快照限制500条当日预约，超过限制明确报错，不能以截断列表充当完整队列。

## 现场规则

1. 预约时段代表到店窗口，暂按30分钟窗口展示，不承诺该分钟开始。仍保留既有档期可预约容量校验；本次没有自动重排未来档期。
2. 顾客到店由前台确认后进入对应发型师的现场队列。未来预约、未到店、暂离、过号不计入可立即服务人数。
3. 暂离登记预计返回时间；顾客点“已返回”只发送待核实请求，前台确认本人在场后恢复队列，防止远程占位。
4. 准备返回是提前提醒，正式叫号才开始10分钟宽限。当前发型师正在服务或暂停接客时，不能正式叫下一位；可以发准备提醒。宽限到期后由前台确认过号，不自动跳号。
5. 首次过号且过号后60分钟内返回，恢复原排队优先级，在当前服务结束后参与排序；再次过号或超过60分钟，按返回时间重新排队。不会打断正在服务者。正常暂离返回保留原优先级。
6. 相同发型师不能同时开始两单，暂停接客期间不能开始新单。前方有现场顾客时提前开单、人工调序都需要原因；保留原始事件与版本。调序不是自动改派发型师。
7. 服务结束必须员工确认，不按倒计时自动完成；结束计时不等于收银、扣款或结算。
8. 同一门店操作串行事务校验；请求带快照版本，重复或过期操作拒绝并刷新。顾客仅见本人排队和消息；员工按店铺、角色、本人发型师范围授权。
9. 只处理预约当天的现场队列。跨日遗留服务/漏记需前台核对并由有权限人员处理，不自动制造到店/开始/结束时间。取消、换人、改期、退款仍走现有授权业务入口，求助不会自动变更订单或退款。

## 不固定时长的等待估计

- 按发型师 × 服务读取近90天有效实际时长（5至480分钟）；至少8个样本时，采用中位数到85分位范围。样本不足用预约参考时长约0.75至1.5倍并标明来源。
- 前方每笔等待服务分别累计；正在服务用最近一次员工更新的剩余时间并保留误差范围。
- 剩余时间耗尽或超过15分钟未更新时扩大不确定性，提醒前台确认；不显示“倒计时到了所以结束”。发型师可直接选择剩余10/20/30分钟。
- 暂停接客显示恢复预期；已等待超过45分钟突出求助和前台关注。预估只辅助沟通，不决定排序，不作为赔偿、准点开始或自动完单依据。

## 验收清单

- 新预约：前台确认到店后，顾客页与另一台工作台在下一次同步展示同一状态；前台按钮不进入多层菜单。
- 暂离→报返回→本人核实：未核实前不能远程插回现场；重复点击不重复变更。
- 叫号→未确认提示→电话联系→顾客确认：区分准备提醒、正式叫号、看到确认、人在场四种事实。
- 叫号10分钟内不能过号；首次过号60分钟内恢复原优先级；重复过号/长时间离开排尾；调序/跳过他人开单必须有原因。
- 发型师暂停/恢复、忙碌时不能重复开单；进度延长同步等待范围，倒计时到零不会自动结束。
- 双设备同时操作同一单：仅一个版本成功；其他设备显示冲突并刷新。其他顾客不能查询本单，其他店员工不能操作，本店发型师只见本人预约。
- 断网/服务异常保留最后数据但停用动作；恢复及回前台立即同步。锁屏期间按人工电话流程实际演练，不能以模拟器页面振动代替通知送达验收。
- 本地覆盖：SQL事务与真实引擎、HTTP处理器范围与脱敏、小程序生命周期及乱序响应、现有安全/登录/预约/安装器回归；真实短信/订阅消息送达和生产库联调不在这些隔离测试证据内。
