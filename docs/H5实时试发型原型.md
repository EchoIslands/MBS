# H5 实时试发型原型

- 原型只保留独立测试路径 `/customer/try-on/:shopId`，顾客店铺页不展示入口；点开摄像头才加载人脸模型。
- 前置摄像头和人脸关键点只在浏览器本机处理，不调用业务 API，不自动保存视频或照片；离开页面、切换到后台或点击关闭时停止视频轨道。
- 目前使用三款本项目 SVG 示意素材进行二维头部跟随，只能验证实时跟随和预约偏好传递。视觉效果像头盔，不可当作真实试发型，不应开放给顾客。发型文案会进入预约备注，但没有自动选择某项收费服务。
- 浏览器需 HTTPS 或 localhost，以及摄像头授权。真机应分别验证 iOS Safari、安卓 Chrome、微信内 H5：授权拒绝、识别不到人脸、侧脸、横竖屏、后台切换、返回关闭摄像头和帧率。
- 静态模型来自 Google MediaPipe face_landmarker/float16/1；`public/ar/wasm` 来自 npm `@mediapipe/tasks-vision@1.2.0` (Apache-2.0)。部署时须一并发布 `public/ar`。模型和 Wasm 共约 18 MB，仅在顾客点击开启后加载；可针对实际设备再缩减。
- 若后续添加拍照保存、分享或上传照片，需要单独设计授权、存储、删除和隐私说明。当前不提供这些功能。
