## 发布顺序（用户手动）

1. 暂停收银并等待旧请求结束。若037尚未安装，先npx tsx scripts/upgrade-payment-audit.ts；重复执行结构迁移不会补写历史款。
2. npx tsx scripts/upgrade-payment-recovery.ts；成功后npx tsx scripts/verify-release.ts，必须passed:true。任一步失败停止，不推送。
3. git add .；git commit -m "fix: 完善历史支付恢复并锁定原单金额"；git push origin main。
4. Vercel新提交Ready后刷新浏览器，开单结算→未完成结算→继续结算：原金额/创建时间不变；点核对并恢复原支付。已付直接同步，未付显示正确金额二维码，未知给明确提示，不另开重复收款。完成后结算管理可按实际微信成功时间定位，商户单号可搜。
5. 真实微信、Vercel函数预算及生产迁移有效权限仍待上线后验证；本地没有微信配置，未核回那笔历史33.64的success_time。旧未核价单、异常多映射单继续要求人工核对，不自动修改历史金额。
