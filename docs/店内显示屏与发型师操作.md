# 店内显示屏与发型师操作

店铺登录后，在实时排队工作台点击“打开店内显示屏”，也可访问 /shop/queue-display。使用店长或负责人账号可显示全店；发型师账号仍仅能查看本人范围。点击全屏进入展示模式。显示屏不展示顾客姓名、电话和交易金额，仅展示发型师、服务状态、服务项目、叫号和现场等候人数。每5秒请求同步，异常或超过20秒未同步时提示核实并隐藏旧业务状态。不是锁屏通知。

发型师用自己的员工账号在手机网页登录，进入发型师看板，点击实时排队工作台，可操作本人顾客的开始、结束服务、剩余时间，以及暂停20分钟和恢复接客。开始/结束必须对应实际服务，暂停不结束当前服务。店长可在工作台统一管理；显示屏为只读，避免顾客误触修改。

本次无需SQL。H5需要部署，小程序首页优化需要重新上传：首页门店和评价请求并行，门店返回立即显示，不再等待评价；不缓存会员价格或排队状态。尚未以店铺手机实测量化提速；首个门店请求、图片下载及弱网仍需现场验证。
